# 問題7.11
## 問題7.10のpushの平均時間計算量
問題7.10では配列を倍々にしていくので、```push```を$`n`$回呼び出したとき、再配置は$`log_2 n`$回発生する。各再配置でコピーが$`1, 2, 4, 8, ..., 2^{log_2 n}`$回行われるので、コピー回数の総和は$`2^0 + 2^1 + 2^2 + ... + 2^{log_2 n}`$回になる。  
初項```a```、公比```r```、項数```m```の等比数列の和は、次の式で求められる。 
```
S = a(r^m − 1) / (r − 1)
```
$`2^0 + 2^1 + 2^2 + ... + 2^{log_2 n}`$に当てはめた場合、$`a=1`$、$`r=2`$、$`m=log_2 n+1`$となるので、コピーの総和は$`2^{log_2 n+1}-1`$となる。  
$`2^{log_2 n+1}-1`$は$`2^{log_2 n} \times 2-1`$となり、$`2^{log_2 n}=n`$となるので、$`n \times 2-1=2n-1`$となる。  
よって、pushを$`n`$回呼び出したときの総作業量は書き込み回数とコピー回数を足した量になるので、$`n+2n-1=3n-1`$となる。  
つまり、push1回あたりの平均は$`(3n-1)/n=3-1/n<3`$となる。  
push1回あたりの平均が定数になる場合、O記法で記載すると、```O(1)```となる。

## copyAとcopyBの時間計算量
copyAでは最初に```Array(array.length)```で長さ```n```の配列を用意し、ループの中では各要素を代入する。  
配列の要素への代入や参照は```O(1)```で行えるものとすると、1回のループでの作業量は```O(1)```となる。  
copyAでは```n```回ループさせるので、$`O(1) \times n=O(n)`$となる。  
一方copyBでは```n```回pushを行う。  
JavaScriptの配列のpushも、問題7.10のpushと同様の仕組みにより平均```O(1)```とみなせる。  
よって、push1回あたりの平均時間計算量は```O(1)```となるので、pushを```n```回呼んだときの合計は$`O(1) \times n=O(n)`$となる。  
結果、copyBよりもcopyAの方が効率的に見えるがcopyAとcopyBとも全体の計算量は一緒になるので、計算量の観点では一緒である。
