## プロンプトと得られたヒントの概要

### 1. 「分割 → reverse → join」の考え方でよいか

> 問題7.8で文字列を入れて逆にする関数を作成するが、考え方としては入力された文字列を各要素として1文字ずつ入れて、reverseしてjoin("")で取り出すでもいいの？

得られたヒント:

- 考え方は合っている。大事なのは「1 文字」をどの単位で区切るか。
- `"家族 👨‍👨‍👧‍👧"` を分割すると、`split("")` (UTF-16 コード単位) は 14 個、`[...str]` (コードポイント) は 10 個、`Intl.Segmenter` (書記素) は 4 個になる。
- 👨‍👨‍👧‍👧 は 👨 + ZWJ + 👨 + ZWJ + 👧 + ZWJ + 👧 でできており、さらに 👨 などはサロゲートペア。`split("")` で反転するとサロゲートペアが壊れ、`[...str]` で反転すると部品と ZWJ の並びが逆になって元の絵文字に戻らない。
- Node の REPL で 3 通りの分割を試して比べ、MDN の `Intl.Segmenter` を読むよう促された。

### 2. Intl.Segmenter の使い方

> Intl.Segmenter 呼んでもよくわからなかった

得られたヒント:

- 「区切る道具を作る (`new Intl.Segmenter("ja", { granularity: "grapheme" })`)」と「文字列を渡して区切る (`segment()`)」の 2 ステップ。`granularity` には `"grapheme"` / `"word"` / `"sentence"` がある。
- `segment()` の戻り値は配列ではない。取り出した要素は文字列ではなく `{ segment, index, input }` のオブジェクトで、1 文字は `segment` プロパティに入っている (`"🇯🇵日本"` を `for...of` で表示する例)。
- 「Segments → ① 配列にする → ② `.segment` を取り出す → `reverse()` → `join("")`」という流れを図で示され、①はスプレッド構文や `Array.from()`、②は 7.8.1 の配列メソッドを使うよう促された。

### 3. segments を出力すると `{}` になる理由

> const segments = segmenter.segment("🇯🇵日本");でsegmentsを出力したら{}だったんだけど、どうなっているの？segmentsって何モノになるの？

得られた回答:

- `segments` は Segments オブジェクト。自身のプロパティを持たないので `console.log` では `{}` と表示される。機能 (`Symbol.iterator`, `containing()`) はプロトタイプ側にある。
- `Symbol.iterator` を持つので `for...of` やスプレッド構文が使える (イテラブル)。区切る処理は取り出すときに 1 つずつ行われる (遅延評価)。
- `index` は「見た目の何文字目か」ではなく UTF-16 コード単位での位置。🇯🇵 は 4 コード単位なので `"日"` の `index` は 4 になる (最初の説明で 2 と書かれていたのを訂正された)。これは問題 7.9 の説明にも使える。
- `console.log([...segments])` で中身を確認するよう促された。

### 4. reverse() / join() の戻り値

> reverse()もjoin()も変数に代入しても大丈夫なやつ？

得られた回答:

- どちらも戻り値があるので代入してよい。
- `join()` は新しい文字列を返し、元の配列は変わらない。
- `reverse()` は破壊的で、元の配列を逆順にしてその同じ配列を返す (`r === a` が `true`)。今回は `[...segments]` で新しく作った配列なので問題ない。
- 元の配列を残したいときは ES2023 の `toReversed()` が使える。

### 5. segment だけを取り出す方法

> スプレッド構文で入れたはいいけど、segmentだけ取り出したい
>
> .mapでそのままつなげて一気にsegmentだけ入れられるのか

得られたヒント:

- `map()` で各要素を変換して新しい配列を作る。課題とは別に、問題 7.4 のデータから `name` を取り出す例 (`data.map((x) => x.name)`) を示された。分割代入 `({ name }) => name` でも書ける。
- `[...segments].map(...)` のようにスプレッド構文に直接つなげられる。`segments` は配列ではないので `segments.map` は `TypeError` になり、`[...]` は省略できない。
- `Array.from(iterable, mapFn)` の第 2 引数を使えば、配列化と変換を 1 回でできる。
- 慣れないうちは途中結果を変数に入れて確認し、動いてから 1 行にまとめるとよい。
- テストでは空文字列や国旗の絵文字も確認するとよい。
