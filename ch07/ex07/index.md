# 問題7.7

## 時間計算量

### 結論
マージソートの時間計算量はO($n\log_2 n$)である。

### 理由

1. merge 1回のコスト
   長さpとqの配列をmergeするとき、pushは2つの配列の要素を足した回数分、つまりp+q回行われる。

2. 1段あたりのコスト
   配列を2つに分けるごとに、段が1段下がっていくとする。
   どの段の場合でも、元の配列の要素はちょうど1回ずつ、どれかのmergeでpushされる。
   そのため、1段あたりのコストは配列の要素の数になる。
   配列の要素数をnとした場合、1段あたりのコストはnになる。

3. 段の数
   配列の要素数をnとした場合、配列を半分に分け続けて1個になるまでの段数$\log_2 n$である。

4. 全体
   配列の要素数をnとした場合、マージソートのコストは以下のようになる。
   (1段あたりのコスト) × (段の数) = n × $\log_2 n$
   よってO($n\log_2 n$)となる。

### 補足
- 配列の分け方は値ではなく位置で決まるので、入力の並び方（ソート済み・逆順など）に関係なく計算量は同じになる。
