# 問題4.5

```javascript
for (i = 1; i < 101; i++)
  console.log((i % 3 ? "" : "Fizz") + (i % 5 ? "" : "Buzz") || i);
```

```i```は1~100の間でループ処理を行う。  
```i % 3```の```%```は余剰演算子で```i```を3で除算したときの余剰を返す。  
余剰が0になったときにfalsyとなり、偽とみなされる。つまり、3の余剰が0以外の場合はtrue、0の場合はfalseとなる。  
よって、```i % 3 ? "" : "Fizz"```では3の余剰が0以外の数字は空文字、余剰が0の数字はFizzを返す。  
```i % 5 ? "" : "Buzz"```も同様に5の余剰が0以外の場合はtrue、0の場合はfalseとなる。  
よって、5の余剰が0以外の数字は空文字、余剰が0の数字はBuzzを返す。  
```i % 3```と```i % 5```がともにfalseになる場合、つまり15の倍数のときはFizzとBuzzの文字列を```+```で連結させるので、FizzBuzzとなる。  
次に、```||```についてだが、これは論理和演算子であり、```x || y```では、```x```がtrueに変換できる場合は```x```を返し、それ以外の場合は```y```を返す。  
つまり、```(i % 3 ? "" : "Fizz") + (i % 5 ? "" : "Buzz") || i```では左の式が3と5の余剰が0出ない場合、空文字になるので、falsyになる。その場合、```i```の値が返される。  
まとめると、1~100の数字の中で、3の余剰が0の場合はFizz、5の余剰が0の場合はBuzz、15の余剰が0の場合はFizzBuzz、それ以外の場合は数字がコンソールログに表示される。
