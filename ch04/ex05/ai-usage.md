## 質問した内容と得られたヒント

### 1. 剰余演算子と truthy/falsy を調べるための資料

- 質問: 剰余演算子の true と false について調べたい。MDN などにいい例はあるか？
- 回答: `%` は正式には「剰余 (remainder) 演算子」と呼ばれ、`%` 自体は boolean ではなく数値を返す。その数値が条件位置に置かれたときに truthy/falsy のルールで解釈されるので、「剰余演算子」と「truthy/falsy」を分けて調べるとよい。参照先として MDN の「剰余 (%)」「Falsy」「Truthy」「条件 (三項) 演算子」「論理和 (||)」のページを紹介された。コンソールで試せる小さなデモ (`Boolean(6 % 3)` が `false` になる等) も提示された。

### 2. 三項式のまとまりの後ろに `||` が付いたときの動作

- 質問: 三項演算子を if/else で書く処理は理解できるが、それを括弧でまとめて後ろに `||` を使うとどういう処理になるのか分からない。
- 回答: `+` は `||` より優先順位が高いので、式は `(三項式A + 三項式B) || i` とグループ化される。`||` は「左オペランドが truthy なら左の値をそのまま返し、falsy なら右の値を返す」演算子で、boolean ではなくオペランドの値そのものを返す。`||` の左側は 4 通りの文字列 (`""` / `"Fizz"` / `"Buzz"` / `"FizzBuzz"`) にしかならないので、そのうちどれが falsy かを考えれば数値が出力されるケースが説明できる、というヒントを得た。
- ここから「空文字は falsy だから `i` が採用される」と自分で理解した。`i % 3` が 0 (falsy) のときの数値の falsy と、`"" || i` の文字列の falsy の 2 段階で falsy を利用している構造であることも確認した。

### 3. 補足として教わったこと

- `x || y` は「デフォルト値へのフォールバック」の定番イディオムだが、`0` や `""` を有効な値として扱いたい場面では潰されてしまう。これが問題 4.6 で出てくる `??` (null 合体演算子) が導入された理由につながる。
