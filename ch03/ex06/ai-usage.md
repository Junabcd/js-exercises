## 相談内容 (プロンプトの要約) と得たヒント

1. **「indexStart が数字か数字以外かで場合分けしたい。数字じゃないなら 0 を入れたい。よい関数は?」**
   → `Number()` で先に変換してから `Number.isNaN()` で判定するパターンを提案された。本物の slice は「数値じゃなければ 0」ではなく「数値に変換して NaN なら 0」(ToIntegerOrInfinity) という順序であること、`Math.trunc()` の存在、indexStart と indexEnd で省略時のデフォルトが違うことのヒントを得た。

2. **「NaN だけでなく小数点の確認など多角的な実装が必要? isNaN は文字列の数字も分けてくれる?」**
   → 「変換 → NaN なら 0 → 切り捨て → 負なら length を足す → クランプ」という正規化パイプラインとして整理する考え方を得た。グローバル `isNaN()`(暗黙変換あり) と `Number.isNaN()`(変換なし・値が NaN かだけ見る) の違いを教わった。

3. **「slice は文字列の数字 ("2" など) でも動くの?」**
   → 動く。組み込みメソッドは引数に ToIntegerOrInfinity をかけるため。

4. **「indexEnd は数値に変換できないものは length になる?」**
   → 誤解を訂正された。length になるのは undefined (省略時) のみで、NaN は 0 になる。`slice(str, 2, NaN)` のテストケースで区別が必要と指摘を受けた。

5. **「小数切り捨てに Number.isInteger() を使うと Infinity も引っかかるのでは?」**
   → 判定ではなく `Math.trunc()` を無条件に通せば整数にも Infinity にも無害、というヒントを得た。

6. **「文字列の取り出しに String 関連の関数を使ったら意味なくない?」**
   → slice/substring をそのまま使うのは本末転倒だが、`str[i]` / `charAt()` での 1 文字アクセス + `+` 連結でループを組むのが趣旨、とのヒントを得た。start >= end のケースはループ条件で自然に空文字になることも教わった。

7. **「Infinity は区別しないと無限ループになるのでは?」**
   → `Math.min` / `Math.max` によるクランプをループの前に通せば Infinity も 100 と同じく丸められるため、専用分岐は不要と教わった。

8. **「テストが複数失敗した。デバッグログを出しつつ失敗したものだけ見たい」(ツール利用の相談)**
   → `npx vitest ch03/ex06` の watch モード + `f` キー (失敗のみ再実行)、`-t` によるテスト名フィルタ、`console.log` の出力がテストごとに表示されることを教わった。

9. **「三項演算子ではなく 1 行の if で書ける?」(スタイル相談)**
   → ブロック省略の 1 行 if が書けること、片側が「何もしない」場合は if の方が意図が伝わることを確認した。
