# AI 利用記録 (問題 3.7)

- 日付: 2026-09-01
- 利用ツール: Claude Code

## 経緯

小数を含んだ定数 (`x = 1.1`, `y = 1.2`) を入れたらテストが通ったが、理由がわからなかったため、AI にヒントを求めた。

## プロンプト

1. 「問題3.7で等価性がないにもかかわらず、等しいと判断される定数を考える問題で少数を含んだものを入れたら当たってしまったが、理由がわかっていない。ヒントください。」
2. (ヒントを受けて) 自分の言葉で理解を説明し、合っているか確認した。

## 得られたヒント (解答コードの提示は受けていない)

- 小数であることは本質ではなく、整数の組み合わせ (例: `x = 1`, `y = 2`) でも通る。
- `equalArrays` を 1 行ずつトレースするよう促された:
  - `(1.1).length` はエラーにならず `undefined` になる (ラッパーオブジェクト、書籍 3.3.4)。
  - `undefined !== undefined` は `false` なので length チェックを素通りする。
  - ループ条件 `0 < undefined` は `<` がオペランドを数値変換するため `0 < NaN` となり、`NaN` が絡む比較はすべて `false` → ループが一度も回らず `return true` に到達する。

## 理解した内容

配列を想定したコードに数値 (基本型) を渡すと、`length` アクセスがエラーにならず `undefined` を返し、以降のチェックがすべてすり抜けて `true` が返る。これが動的型付け言語で型を確認しないコードの落とし穴であり、本問題の意図。
