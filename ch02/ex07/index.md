# 問題2.7
出力結果は以下のようになった。
```
0 1 0
1 1 0
```
console.log(a, b, c);までの処理の流れを説明する。
```
const c
=
a
++
b
```
となっているが、++演算子で改行が入っているため、前置演算子として処理される。セミコロンを使用すると
```
const c = a;
++b;
```
と書ける。a,bの初期値はともに'0'のため、cには'0'が代入される。  
さらに前置演算子によって、bの値がインクリメントされるので、bの値は'1'となる。そのためconsole.log(a, b, c);は
```
0 1 0
```
と表示される。  
次に、console.log(a, b, e);までの処理の流れを説明する。
```
const e = a++
b;
```
となっているが、今回は変数aと++演算子が1行で書かれているため、後置演算子として処理される。  
そのため、eには'0'の値が代入された後に、aの値がインクリメントされるので、aの値は'1'となる。  
bの値は前段の処理で'1'の値が入っているため、console.log(a, b, e);は
```
1 1 0
```
と表示される。  
よって、index.jsの表示は
```
0 1 0
1 1 0
```
となる。
