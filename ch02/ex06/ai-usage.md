## 質問と得たヒントの要約

1. **JavaScript の関数の定義方法は？**
   - 関数宣言 / 関数式 / アロー関数の 3 つの書き方と使い分け（巻き上げ、`this` の違い）の説明を受けた。

2. **問題文の「1〜100 まで繰り返す」はテスト側？関数側？**
   - テストコードの `fizzbuzz()` が引数なしで 1 回だけ呼ばれ、戻り値を 1 つの文字列と比較していることから、繰り返しと文字列の組み立ては関数側で行う必要があると読み解くヒントを得た。

3. **セミコロンを多用して 1 行で書けという意図？**
   - README の問題 2.6 を確認し、「1 行で書きなさい」という指定があることを確認。
   - 「文を並べる（セミコロン必要）」か「全体を 1 つの式にする（セミコロン不要）」の 2 つの道があるという整理を得た。
   - 長い 1 行は Prettier に整形されるため `// prettier-ignore` が使えることも教わった。

4. **条件演算子を何個も並べることになるのでは？**
   - 条件演算子の連鎖は `if / else if / else` と同じ構造で、多分岐の定石であるとの説明。判定の順番（15 の倍数を先に見る）の注意を得た。

5. **`a==0?"a"?"b":"c"` のように `?` を 2 つ並べるとどうなる？**
   - 答えではなく「`?` と `:` は必ず対になる」「Node.js の REPL で試して確認する」という検証方法を教わった。

6. **3 択（3 の倍数 / 5 の倍数 / それ以外）を if if else のように書きたい**
   - 独立した 2 つの条件演算子の結果を文字列連結で合成する発想、該当しない場合は空文字列を返すこと、falsy と `||` がオペランドを返す性質を調べるようヒントを得た。

7. **結果はどこかに格納しないといけない？**
   - `console.log` は値を返さないので不可。文で書くならアキュムレータ変数が必要、式で書くなら `map` / `join` が値を返すので変数は不要という整理を得た。

8. **`while` は繰り返した値を全部出力してくれる？**
   - ループ文は値を集めない（各回の値は捨てられる）、`n => ...` は関数定義であって繰り返しではない、収集までやってくれるのは `map` などの配列メソッド、という違いの説明を受けた。

9. **`map` の結果は配列だから `expect` の文字列と一致しないのでは？**
   - その通りで、`join("\n")` で 1 つの文字列にするというヒントを得た。`join` は末尾に区切り文字を付けないので、expected の末尾の改行に注意という指摘も受けた。

10. **`while` で 1〜100 の配列を作るのは簡単？**
    - 可能だが文の世界に戻る。式 1 つで連番配列を作る方法として MDN の `Array.from()`（特に第 2 引数と `{ length: ... }`）を調べるようヒントを得た。インデックスが 0 始まりであることによるずれの注意も受けた。

11. **`TypeError: fizzbuzz is not a function` が出た**
    - 関数を定義しても `export` していないと import 側で `undefined` になるため、named export を追加するようヒントを得た。
