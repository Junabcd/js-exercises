# 問題2.2
## $を使用したライブラリ
```
jQuery（ジェイクエリー）
```
DOM(Document Object Model)要素の選択や操作に使用するライブラリ。  
JavaScript はもともと「Web ページを動かすための言語」として生まれた。なので、ブラウザ上の JavaScript がやることの大部分はDOM操作になる。jQueryの使用頻度はかなり多かったこともあり、「$」で呼べるようになった。  
現在はjQueryでやっていたことの多くは、標準のdocument.querySelector()などで簡単に書けるようになった。

## _を使用したライブラリ
```
Underscore.js と Lodash（ロダッシュ）
```
配列やオブジェクトを扱うためのライブラリ。  
JavaScript でデータを扱うとき、その入れ物はほぼ「配列」か「オブジェクト」の2択。サーバーから受け取るデータも、画面に表示する一覧も、設定情報も、全部この2つで表現される。JavaScriptでは配列やオブジェクトを加工する処理が大量に出てくることもあり、「_」で呼べるようになった。  
Lodash の機能の多くは、標準の map() / filter() / Object.keys() などに取り込まれた。

使用頻度も多かったこともあるが、「$」と「_」は「合法だけど普通の人はまず使わない記号」だったので、ライブラリが名乗るのにちょうどよかったという背景もあった。（早い者勝ち）
