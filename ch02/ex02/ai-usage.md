# AI 利用記録 (ch02/ex02)

## 利用した AI

Claude Code (モデル: Fable 5)

## 目的

`$` や `_` を変数名として利用するライブラリについての調査 (課題の解答作成の参考)

## 実際に入力したプロンプト

1. 「$ や \_ を変数名として利用するライブラリについて調べてください。」
2. 「初心者にもわかりやすいように、わかりやすい言葉で説明してください。」
3. 「JS では Web ブラウザの操作や配列、オブジェクトの使用頻度がかなり高い？この二つのライブラリが一文字で使用できるようになった背景にはライブラリの呼び出しの頻度が群を抜いているからだと思ったので。」

## AI の回答の要約

- `$` と `_` は JavaScript の識別子として合法な文字であり、1 文字だけでも変数名になれる。
- `$` を使う代表的なライブラリ: jQuery (元祖は Prototype.js、他に Zepto.js)。`$` は `jQuery` 関数の別名。
- `_` を使う代表的なライブラリ: Underscore.js と Lodash。配列・オブジェクト操作のユーティリティ集。
- 1 文字の名前が選ばれた背景: DOM 操作や配列・オブジェクト操作は呼び出し頻度が非常に高く、短い名前ほど書く・読む負担が減るため。加えて `$` と `_` は「合法だが普通は使われない記号」で空いていた。
- 自分のコードの通常の変数名に `$` や `_` を使うのは、ライブラリと紛らわしいため推奨されない。
- 現在は `document.querySelector()` や標準の配列メソッドの充実により、これらのライブラリの出番は減っている。
