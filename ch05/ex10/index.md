# 問題5.10
## コードの説明
```JavaScript
{
  let a = 1;
  let b = 2;
  let obj = { a: 3, b: 4 };
  with (obj) {
    a = b;
  }
  console.log({ a, b, obj });
  // console.log の出力: { a: 1, b: 2, obj: { a: 4, b: 4 }}
  // with 文を使わずに同じ処理を書く場合: obj.a = obj.b
}
```
```with(obj){a = b}```を実行する際、まず```with(obj)```に到達した時点で宣言されている```let obj = { a: 3, b: 4 };```を取得する。  
```{a = b}```で```obj```のプロパティとして```a```と```b```があるか、つまり```obj.a```と```obj.b```をチェックする。  
今回のコードでは```obj = { a: 3, b: 4 }```でプロパティ```a```と```b```が存在するので、```{a = b}```は```{obj.a = obj.b}```となる。  
出力結果は```{ a: 1, b: 2, obj: { a: 4, b: 4 } }```となった。 

```JavaScript
{
  let a = 1;
  let b = 2;
  let obj = { b: 4 };
  with (obj) {
    a = b;
  }
  console.log({ a, b, obj });
}
```
同様に、このコードでは```let obj = { b: 4 };```と宣言されており、プロパティ```b```のみ存在する。  
この場合、```{a = b}```の```b```の方はプロパティとして存在するので、```obj.b```となる。  
しかし、プロパティ```a```は存在しないため、```a```の宣言を探索し、```let a = 1;```の```a```が見つかる。  
よって、```a```は```obj.a```ではなく、```a```として扱われるので、```{a = b}```は```{a = obj.b}```となる。  
出力結果は```{ a: 4, b: 2, obj: { b: 4 } }```となった。 

```JavaScript
{
  let a = 1;
  let b = 2;
  let obj = { a: 3 };
  with (obj) {
    a = b;
  }
  console.log({ a, b, obj });
}
```
このコードでは```let obj = { a: 3 };```と宣言されており、プロパティ```a```のみ存在する。  
この場合、```{a = b}```の```a```の方はプロパティとして存在するので、```obj.a```となる。  
しかし、プロパティ```b```は存在しないため、```b```の宣言を探索し、```let b = 2;```の```b```が見つかる。  
よって、```b```は```obj.b```ではなく、```b```として扱われるので、```{a = b}```は```{obj.a = b}```となる。  
出力結果は```{ a: 1, b: 2, obj: { a: 2 } }```となった。 

```JavaScript
{
  let a = 1;
  let b = 2;
  let obj = {};
  with (obj) {
    a = b;
  }
  console.log({ a, b, obj });
}
```
このコードでは```let obj = {};```と宣言されており、プロパティ```a```もプロパティ```b```も存在しない。  
この場合、```{a = b}```の```a```も```b```もそれぞれ変数の宣言を探索し、```let a = 1;```と```let b = 2;```が見つかる。  
よって、```a```、```b```として扱われるので、```{a = b}```は```{a = b}```となる（変数```a```に変数```b```の値を代入）。  
出力結果は```{ a: 2, b: 2, obj: {} }```となった。  

## with文について
このようにwith文を使用すると、プロパティがあるかないかで代入先が変化してしまい、オブジェクトの中身を知らないでコードを読むと、どのような実行が行われているかわからなくなってしまう。  
可読性を下げ、バグの元になるので、Strictモードでは使用が禁止されている。
