# 問題5.3
if-else文：少ない分岐では読みやすい（条件が2~3個）、三項式などの複雑な条件式にも柔軟に対応できる。複数条件にも対応しやすい。    
switch文：単一の値の分岐を書く場合ではswitch文を使う方が読みやすい（```===```で比較されるので、```s==="a"```のように書かなくてよい）、条件が多い場合はif-else文よりも直感的で読みやすい（条件が10個など）。
