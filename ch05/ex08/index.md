# 問題5.8
catchブロックにbreak文、finallyブロックにcontinue文が記載されている関数の実行結果について予想する。  
for文の中で```i=1~5```でループし、```i```の値を```x```に代入してループを抜けた後に、```console.log```に出力して、何が出力されるかについてだが、```5```が出力されると予想する。  
tryブロックでは```throw Error();```が書かれているため、tryブロックを通った後に、catchブロックへと処理が移動する。  
教科書のP131に書いてある「return文やcontinue文、break文で処理がtryブロックから移動する場合は、処理が移動する前にfinallyブロックが実行されます。」ということから、catchブロックに書かれている```break;```でcatchブロックから移動してしまう前にfinallyブロックが実行される。  
finallyブロックでは```continue;```が書かれているため、ループを抜けず、ループの先頭に戻る。    
その結果、```i=5```まではループを続け、```x```に```5```が代入された後にループを抜け、```console.log```が実行される。  
よって、問題5.8のコードを実行して```console.log```で出力すると、```5```と表示される。  
実際に```index.js```で実行した結果、```5```が出力されたことを確認した。
